Hi Guys!

This is Simulacra. A project built by SeaCleaver (Conan) to help understand 
trading systems and how trading bots work.

The plan right now is to build a Limit Order Backtesting Engine. This engine 
will be fed training data tick by tick from a sheet of historical trading data.
If time allows, I seek to use randomisation to make the engine better at
handling unpredictable data.

Tech Stack:
- Language is Python.
- Libraries used include numPy and Pandas.
